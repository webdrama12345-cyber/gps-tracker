# 📍 GPS Location Tracker - Developed by Qamar Mushtaq

A Live GPS Location Tracker with Grid Reference, Accuracy, Altitude, Speed and Google Maps Link.
Made with HTML, CSS, JavaScript + Geolocation API. No API Key Needed.

## Features
- Live Latitude & Longitude (6 decimal - Correct Location)
- Accuracy in Meters
- Altitude & Speed
- Grid Reference (UTM Zone + Easting / Northing)
- Plus Code / Coordinates
- Google Maps Link - One Click Open
- Copy Location Button
- Works on Mobile + Computer

## How to Use
1. Open `index.html`
2. Click "Get My Current Location"
3. Allow Location Permission
4. Your correct location will show
